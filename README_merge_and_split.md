# merge_and_split.py

Склейка нескольких PNG-изображений в одно длинное полотно, затем интеллектуальная нарезка на части по пустым полосам. Каждый итоговый файл сохраняется с DPI 300 в метаданных.

## Зависимости

```
pip install Pillow numpy
```

## Быстрый старт

```bash
python merge_and_split.py page1.png page2.png page3.png
```

Программа спросит имя папки для результатов. Все нарезанные части (`part_000.png`, `part_001.png`, ...) будут сохранены туда.

## Что делает программа

1. **Склейка** — объединяет входные PNG в одно изображение (по умолчанию вертикально).
2. **Нарезка** — анализирует яркость строк и режет по пустым (белым) полосам, стараясь делать куски ~3000 px по высоте. Если пустая полоса не найдена рядом с целевой точкой — режет ровно по ней.
3. **DPI 300** — каждый кусок сохраняется с метаданными `dpi=(300, 300)`, чтобы приложения для чтения не ругались на низкое разрешение.
4. **Выходная папка** — результаты помещаются в новую папку, имя которой вы задаёте при запуске.

## Параметры

| Флаг | По умолчанию | Описание |
|------|-------------|----------|
| `-d`, `--direction` | `vertical` | Направление склейки: `vertical` / `horizontal` |
| `--gap` | `0` | Отступ между изображениями (px) |
| `--bg` | `white` | Цвет фона: `white`, `black`, `transparent` |
| `--resize` | `none` | Подгонка размеров: `none` / `fit_width` / `fit_height` |
| `--chunk-height` | `3000` | Целевая высота одного куска (px) |
| `--min-blank` | `30` | Минимальное количество пустых строк для разреза |
| `--padding` | `15` | Отступ от края разреза (px) |
| `--threshold` | `250` | Порог яркости для определения пустой строки (0–255) |
| `--output-dir` | *(спросит)* | Имя выходной папки (если не указано — спросит интерактивно) |

## Примеры

```bash
# Склеить вертикально и нарезать, результат в папку "chapter_01"
python merge_and_split.py *.png --output-dir chapter_01

# Горизонтальная склейка с отступом
python merge_and_split.py a.png b.png -d horizontal --gap 20 --output-dir result

# Более мелкая нарезка
python merge_and_split.py *.png --chunk-height 2000 --output-dir small_parts
```
